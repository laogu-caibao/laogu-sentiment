# 数据源（2026-09-29 实测）

> 实测环境：本沙箱，北京时间 2026-09-29（周二，交易日）15:00 后。结论：东财 push2 系列在本沙箱不可用（TCP 超时）；新浪/腾讯行情、东财 datacenter-web 可用。

## 一、程序化接口（亲手 curl 验证）

### 1. 新浪行情（可用 ✅ 2026-09-29 实测）

```
https://hq.sinajs.cn/list=s_sh000001,s_sz399001,s_sz399006
```

- 请求要求：桌面端 UA + Referer 头 `https://finance.sina.com.cn/`；返回 GBK 编码，需 `iconv -f GBK -t UTF-8` 转码
- 用途：指数涨跌幅（D5 辅助）、盘中成交额同口径环比
- 实测返回示例：`var hq_str_s_sh000001="上证指数,3830.4513,6.8307,0.18,3994733,66170429";`
- **注意**：指数成交额字段单位不明（实测值与实际量级不符），仅同口径环比可用，绝对值以媒体/Wind 口径为准（与 laogu-close 一致）

### 2. 腾讯行情（可用 ✅ 2026-09-29 实测）

```
https://qt.gtimg.cn/q=s_sh000001,s_sz399001,s_sz399006
```

- 请求要求：桌面端 UA 即可，无需特殊 Referer
- 用途：同新浪，互为备份；Fallback 链：腾讯 → 新浪 → 网页搜索
- 实测返回示例：`v_s_sh000001="1~上证指数~000001~3830.45~6.83~0.18~399473391~66170429~~681407.18~ZS~";`
- 注意：同上，成交额字段仅环比可用

### 3. 东财 datacenter-web 龙虎榜（可用 ✅ 2026-09-29 实测）

```
https://datacenter-web.eastmoney.com/api/data/v1/get?reportName=RPT_DAILYBILLBOARD_DETAILSNEW&columns=SECURITY_CODE,SECURITY_NAME_ABBR,TRADE_DATE,EXPLAIN,BILLBOARD_NET_AMT&source=WEB&client=WEB&filter=(TRADE_DATE='2026-09-28')&pageSize=50&pageNumber=1
```

- 关键字段：`EXPLAIN`（席位标签，如"深沪股通专用席位净买入"）、`BILLBOARD_NET_AMT`（净买额）
- 用途：D7 辅助定性——统计当日 EXPLAIN 含"深沪股通专用"的条数，描述外资席位活跃度
- 实测 2026-09-28 返回 67 条记录，success:true
- 注意：公共接口不返回营业部席位明细，只到标签级；columns 参数必填，否则报 9501

### 4. 东财 push2 / push2his（本沙箱不可用 ❌ 2026-09-29 实测）

- `https://push2.eastmoney.com/api/qt/...`（clist/ulist）：curl 返回 000，TCP 超时
- `https://push2his.eastmoney.com/api/qt/stock/kline/get`：同样超时
- 结论：涨停数/跌停数/历史成交额的程序化路径在本沙箱走不通，文档中降级为网页搜索；其他网络环境可用时可作为备选（涨停池 clist、指数 kline 成交额 f57 字段）

## 二、网页搜索路径（主力，搜索模板 + 2026-09-29 实测命中）

| 维度 | 搜索关键词模板 | 稳定来源（2026-09-29 实测命中） |
|---|---|---|
| D1 涨跌家数比 | `A股 收盘 涨停 家数` / `A股 收评 涨跌家数` + 日期 | 证券时报·数据宝收盘复盘、新浪财经收评、东方财富快讯 |
| D2 涨跌停家数比 | 同上（数据宝固定披露"涨停 X 只，跌停 X 只"） | 同上 |
| D3 连板高度 | `涨停板复盘 连板` + 日期 | 南方财经、财联社、第一财经、每经 AI 快讯 |
| D4 炸板率/封板率 | `封板率` + 日期（南方财经每日 15:52 左右发布） | 南方财经（"22股封板未遂，封板率71%"）、每经 AI 快讯 |
| D5 两市成交额 | `两市成交额` + 日期 | 上海证券报·中国证券网、上证报、数据宝盘中播报 |
| D6 流通市值 | `上交所 市场总貌 流通市值` + 日期 | 上交所/深交所官网每日披露 |
| D7 北向成交占比 | `X月X日北向资金最新动向 东方财富` | 东方财富研究中心（每日 17:30 左右发布，含成交总额及占比） |

**北向口径红线**：2024 年 5 月后北向净流入已不再披露，只找成交总额及占比，不找净流入（与 laogu-close / laogu-moneyflow 一致）。

## 三、降级链总表

```
D1/D2/D3/D4：数据宝收盘复盘 → 南方财经/财联社复盘 → 新浪财经收评 → 标注"未核验"
D5：媒体两市成交额 → 新浪/腾讯指数成交额同口径环比 → 标注"未核验"（历史分位缺基线时降级为"较昨日"口径）
D6：上交所/深交所官网市场总貌 → 标注"未核验"（该维允许缺失）
D7：东财研究中心北向动向 → datacenter-web 龙虎榜股通席位定性 → 标注"未核验"
```

## 四、兜底规则

- 每个数据点最多尝试 2 个来源，仍取不到即标"未核验"，不反复死磕
- 已核验维度 N<5 时，不强行判定阶段，只输出"数据不足，暂不判定"并列出缺口
- 60 日成交额历史序列由执行方维护（如 laogu-mcp 每日快照）；skill 首轮运行无基线时 D5 按"较昨日"口径降级并注明
